# Number Guessing Game

Console game where the player guesses a random number from 1 to 100.

## Features
- Hints: higher / lower after each guess
- Handles non-number input without crashing
- Play again option

## How to run
Open `src/App.java` in VS Code and press **Run**, or:
```
javac src/App.java -d bin
java -cp bin App
```

## What I practiced
`Scanner`, `Random`, loops, input validation, splitting code into methods.
